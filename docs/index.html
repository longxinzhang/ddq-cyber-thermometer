DDQ's Cyber Thermometer

动动枪赛博体温计，一个安静待在 macOS 顶栏里的电脑状态小组件。内存、CPU、核心温度、下载和上传速率，一眼看完；点击可打开常用网页、查看月历、风扇转速、开机启动和在线升级。

只占一小块顶栏，但保留最关键的状态。

迷你柱显示内存压力、内存占用和 CPU 占用，温度、下载和上传速率紧贴在旁边。鼠标移上去再显示完整数值，平时不打扰工作。

代码开放，安装包放在 GitHub Release。当前版本是 v0.8.2。

打开 Release 下载
  1. 下载获取 `DDQs-Cyber-Thermometer-0.8.2.dmg`。
  2. 安装打开 DMG，把 App 拖到 Applications。
  3. 运行打开后它会出现在顶栏，不显示 Dock 图标。

当前包是本地临时签名，未做 Apple Developer ID 公证。首次打开如遇系统拦截，可右键 App 选择“打开”，或在“系统设置 > 隐私与安全性”里允许打开。
